Adobe Illustrator is the industry-standard vector graphics application. Its developer platform offers scripting APIs, UXP plugins, CEP extensions, and a C++ SDK for building custom integrations and automating workflows.

**Areas:** Creative Cloud · Design · Illustrator · Vector Graphics

### APIs (11)

- [Adobe Illustrator Plugin SDK](https://apis.io/apis/adobe-illustrator/plugin-sdk/) — The Adobe Illustrator Plugin SDK enables developers to build native C++ plug-ins for Illustrator on Windows and macOS. The SDK opens the entire application…
- [Adobe Illustrator CEP Extensions API](https://apis.io/apis/adobe-illustrator/cep-extensions/) — The Adobe Illustrator Common Extensibility Platform (CEP) allows developers to build panels and extensions using HTML, CSS, and JavaScript. CEP extensions…
- [Adobe Illustrator Application API](https://apis.io/apis/adobe-illustrator/adobe-illustrator-application-api/) — Access to the Illustrator application object, including preferences, version information, and global settings.
- [Adobe Illustrator Artboards API](https://apis.io/apis/adobe-illustrator/adobe-illustrator-artboards-api/) — Manage artboards within an Illustrator document, including creating, resizing, reordering, and removing artboards.
- [Adobe Illustrator Documents API](https://apis.io/apis/adobe-illustrator/adobe-illustrator-documents-api/) — Manage Illustrator documents, including opening, creating, saving, closing, and exporting documents in various formats.
- [Adobe Illustrator Graphic Styles API](https://apis.io/apis/adobe-illustrator/adobe-illustrator-graphic-styles-api/) — Manage graphic styles that can be applied to artwork for consistent appearance across multiple objects.
- [Adobe Illustrator Layers API](https://apis.io/apis/adobe-illustrator/adobe-illustrator-layers-api/) — Create, manage, and manipulate layers within an Illustrator document, including visibility, locking, and ordering.
- [Adobe Illustrator Path Items API](https://apis.io/apis/adobe-illustrator/adobe-illustrator-path-items-api/) — Create and manipulate vector path items, including shapes, lines, and complex paths with anchor points and control handles.
- [Adobe Illustrator Swatches API](https://apis.io/apis/adobe-illustrator/adobe-illustrator-swatches-api/) — Manage color swatches, including spot colors, process colors, gradients, and patterns stored in the document.
- [Adobe Illustrator Symbols API](https://apis.io/apis/adobe-illustrator/adobe-illustrator-symbols-api/) — Manage symbol definitions and symbol instances, enabling reuse of artwork across documents.
- [Adobe Illustrator Text Frames API](https://apis.io/apis/adobe-illustrator/adobe-illustrator-text-frames-api/) — Create and manipulate text frames, including point text, area text, and text on a path, with full typography control.

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Adobe Illustrator: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
